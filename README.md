# FNFgame

FNF（Friday Night Funkin'）風のブラウザ音ゲーです。HTML5 Canvas + Web Audio API で動作し、外部ライブラリは不要です。

## 遊び方

`index.html` をローカルサーバー経由で開きます（音源・譜面の `fetch` のため `file://` 直開きではなく HTTP が必要です）。

```bash
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

### 曲選択画面（ネオンUI）

- **↑ / ↓** または **カード click** で曲を選択
- **Enter** または選択中カードの再クリックで決定
- 画面下の **✎ 譜面エディタ** ボタンでエディタへ

### プレイ

レーンは **D F J K**（または **← ↑ ↓ →**）に対応。降ってくるノーツを判定ラインで叩きます。
判定は Sick / Good / Bad / Miss。ホールドノーツは押しっぱなしで拾います。

## 譜面エディタ（`editor.html`）

譜面作成を簡単にするビジュアルエディタです。

- 🎵 **音源ファイルを読み込み**（.ogg/.mp3/.wav）してその場で再生プレビュー
- 4レーンのビートグリッドに **クリックでタップ配置 / 下方向ドラッグでホールド配置 / 既存ノーツをクリックで削除**
- **BPM・オフセット・スナップ**（1/1〜1/16、3連符対応）を設定
- **Space** で再生/一時停止、再生ヘッドに合わせて自動スクロール、ノーツヒット音・メトロノーム付き
- **ホイール**でスクロール、**+ / −** でズーム
- **⬇ JSONダウンロード** / **📋 クリップボードにコピー** でゲームと同じ形式の譜面を出力
- **📂 既存JSONの読み込み**で編集を再開（複数BPM・スクロール変化も保持）
- 「詳細設定」で `bpmEvents` / `scrollEvents` を直接編集可能

作成した `<曲>.json` と音源ファイルを同じフォルダに置き、`main.js` の `charts` 配列にタイトルとファイル名を追加すれば曲選択画面に並びます。

## 譜面フォーマット

```json
{
  "music": "song.ogg",
  "offset": 0,
  "bpmEvents":    [{ "beat": 0, "bpm": 120 }],
  "scrollEvents": [{ "beat": 0, "speed": 1.0 }],
  "notes": [
    { "beat": 2,  "lane": 0, "type": "tap" },
    { "beat": 4,  "lane": 1, "type": "hold", "length": 1.5 }
  ]
}
```

- `lane`: 0=左, 1=上, 2=下, 3=右
- `type`: `"tap"` または `"hold"`（`hold` は `length` を拍単位で指定）
